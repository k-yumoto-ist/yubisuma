# Hand image assets

The game uses two completed image assets as its single visual source of truth:

- `fist-right.png`: closed hand.
- `thumb-up-right.png`: raised-thumb hand.

The left slot uses the exact same file with a horizontal CSS mirror. There are no separate left-hand crops, so pose, scale, padding, baseline, shading, and illustration style stay synchronized for CPU and player.

The source artwork was supplied by the project owner and is bundled locally; no external image URL or generated hand path is used.
